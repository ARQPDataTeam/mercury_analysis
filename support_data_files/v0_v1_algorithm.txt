step 1: copy kitid from v0 table: 
mpn__dma_v1.kitid = mpn__dma_v0.kitid

step 2: copy start and end dates for sample tracking to v1 table
mpn__dma_v1.start_dt = pas_tracking table.sample_start 
mpn__dma_v1.end_dt = pas_tracking table.sample_end

step 3: calculate duration (days) between start and end:
mpn__dma_v1.smp_dur = mpn__dma_v1.end_dt-mpn__dma_v1.start_dt

for each kitID there are 3 samples each with 2 sectors:

ECCC#### is the sampleID (smpid)
EC-#### is the kitID (kitid)

loop through the kitid list:
list the smpid values where smptyp=='sample'
add the blank values for that kit: mpn__dma_v1.b_mass = sum(hg) where smptyp=='blank'
add the sector values for each sample: i.e. mpn__dma_v1.s[i+1]_mass = sum(hg) where smpid==id[i] and smptyp=='sample'
average the sample masses: mpn__dma_v1.av_mass = average(mpn__dma_v1.s1_mass,mpn__dma_v1.s2_mass)
calculate blank corrected mass: mpn__dma_v1.bcorr_mass = mpn__dma_v1.av_mass-mpn__dma_v1.b_mass
calculate the sample concentration: mpn__dma_v1.conc = mpn__dma_v1.bcorr_mass/(mpn__dma_v1.smpdur*mpn__dma_v1.flow)
calculate the met corrected sample rate: 
mpn__dma_v1.adj_flow = 0.111+(mpn__dma_v1.tempa-9.89)*0.0009+(mpn__dma_v1.ws_mean-3.41)*0.003
calculate met corrected sample concentration: mpn__dma_v1.adj_conc = mpn__dma_v1.bcorr_mass/(mpn__dma_v1.smpdur*mpn__dma_v1.adj_flow)
